**verify:** Import all modules without error

---

## Task 2: Build NotificationDispatcher with queue and retry

**files:** `notifications/dispatcher.py`
**action:**
- Create async `NotificationDispatcher` class
- On init: read `notifications.yaml`, connect to OpenClaw gateway WebSocket
- `send(event_type, data)` → format template → push to async queue
- Background worker drains queue, sends `event.signal` frames to gateway
- Graceful failure: wrap all sends in try/except, never crash the scan
- Queue notifications if gateway temporarily offline
- Retry failed notifications up to 3 times with exponential backoff
- Severity filtering: skip notifications below `min_severity`
- Critical findings always bypass severity filter

**verify:** Dispatcher initializes, queues messages, handles offline gateway gracefully
**done:** Dispatcher sends formatted notifications through the gateway WebSocket

## Task 3: Wire dispatcher into NeuroRift pipeline and add CLI command

**files:** `main.py`, `ai/executor.py`, `NeuroCore/neurocore/cli/__main__.py`
**action:**
